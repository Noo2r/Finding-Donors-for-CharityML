# Finding Donors for CharityML

## Overview
This project focuses on building a supervised machine learning model to identify individuals most likely to donate to a charity organization using demographic data from the U.S. Census dataset.

The project includes data preprocessing, feature engineering, model training, evaluation, optimization, and visualization.

---

## Objectives
- Analyze census demographic data
- Predict whether an individual is likely to donate
- Compare multiple supervised learning algorithms
- Improve model performance through optimization
- Generate business insights using data visualization

---

## Dataset
The dataset is based on U.S. Census demographic information and contains:
- 32,000+ records
- 13 demographic features

### Features Include:
- Age
- Education Level
- Occupation
- Marital Status
- Hours per Week
- Capital Gain/Loss
- Native Country
- Income Level
